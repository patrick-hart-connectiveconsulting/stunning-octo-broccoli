Streams UI

Web components that turn Media Manager streams into HTML. Every example below is live: it reads the demo streams from this server. Open “Show code” to copy an example. Put <script type="module" src="…/ui/streams-ui.js"></script> once in your page, then use the elements.

The demo streams are missing. Start the server, then enter npm run seed:demo and refresh this page.

Banner

The latest announcement. Rotates and can be dismissed.

List

A vertical list with images, dates and tags. Links use your own URL pattern.

Horizontal list

layout="horizontal" scrolls sideways and snaps to each item.

Cards

A responsive grid. This one uses CSS variables for brand colours, radius and font.

Tag filter

<stream-filter> reads the tags of another component's stream and filters it.

Carousel

Testimonials, two per view, with autoplay that pauses on hover and respects reduced motion.

Calendar

Month, week and agenda views. Colours come from the first tag. On narrow screens the month view becomes an agenda.

Next up

The next upcoming event, with a countdown.

Timeline

Blog posts by month. Add alternate for a zig-zag layout on wide screens.

Table

Sortable columns and a search box.

Map

Every item with a map pin. Click a pin for details.

Gallery

Images from a stream, with a keyboard-friendly lightbox.

Single item

One post, looked up by its slug, with the Markdown body rendered and structured data for search engines.

Dark theme

theme="dark", or theme="auto" to follow the visitor's system setting.

Style with ::part()

Target named pieces of the component from your own CSS.

Unstyled (your own CSS)

unstyled renders plain markup with sui-* classes and no built-in styles, so your site's CSS applies.

Your own markup

Put a <template> inside the element. With unstyled, your page's CSS styles the result (here: .team-grid .sui-cards and .team-card). data-field, data-html (Markdown), data-src, data-href, data-date, data-if and data-each fill it in.

FAQ with <details>

A template turns a FAQ stream into an accordion.

JavaScript rendering

Set renderItem for full control. Escape values with the helper you get.
